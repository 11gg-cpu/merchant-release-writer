# 发布与交接

## 能力检测

1. 确认用户是否明确要求外部写入。
2. 确认当前环境是否有已授权的文档、云盘、浏览器或表单能力。
3. 只读取完成当前任务所需的最小范围，不扫描无关目录、账号或记录。
4. 目标不明确、权限不足或环境无法区分时停止外部写入，保留本地发布包。

## 写入顺序

1. 创建或定位草稿文档。
2. 一次性写入已验证正文，插入与图位对应的图片。
3. 重新读取文档，核对标题、段落、图片顺序和链接。
4. 填写发布表单时逐项核对字段标签与目标环境，不依赖旧的字段顺序。
5. 停在最终提交、发布或更新按钮前，把页面交给用户。

## 失败恢复

- 登录或授权失效：只说明当前必要动作，用户恢复后从失败点继续。
- 文档写入失败：保留本地稿，不重复创建多个草稿。
- 图片失败：记录具体图位和文件，不用无关图片替代。
- 表单结构变化：重新识别字段，禁止猜测或写入生产记录试错。
- 用户看不到已填内容：视为交接失败，在用户可见页面恢复，不宣称已完成。

## 最终提交

AI 可以准备、填写和校验，但不得点击会正式提交、发布、更新或通知外部人员的最终按钮，除非用户在当前任务中对该具体动作给出明确授权且系统政策允许。默认由用户亲自完成。
