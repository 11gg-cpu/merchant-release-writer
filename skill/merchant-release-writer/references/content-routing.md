# 内容类型路由

## 选择规则

| 类型 | 适用场景 | 推荐结构 |
| --- | --- | --- |
| `single` | 一个明确能力或入口更新 | 场景痛点 → 新能力 → 操作步骤 → 条件与提醒 |
| `standard` | 一次完整产品上线，包含多个关联能力 | 上线概览 → 核心能力 → 使用流程 → 适用范围 → 注意事项 |
| `campaign` | 营销工具、活动玩法或增长方案 | 经营场景 → 玩法机制 → 配置步骤 → 示例 → 风险与限制 |
| `digest` | 同一版本或周期内的多项更新 | 本期摘要 → 分项更新 → 影响范围 → 升级与支持 |
| `announcement` | 规则调整、迁移、下线或重要通知 | 发生什么 → 影响谁 → 时间线 → 用户动作 → 支持渠道 |

## 判断顺序

1. 存在迁移、下线、强制变化或时间窗口时优先选 `announcement`。
2. 多项彼此独立的更新选 `digest`。
3. 以活动机制和经营玩法为中心选 `campaign`。
4. 单一能力选 `single`，其余完整发布选 `standard`。

不要为了篇幅把一个能力拆成合集，也不要把多项无关更新硬写成单能力稿。
