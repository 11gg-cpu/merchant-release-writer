# 发布稿质量门禁

## 事实

- 每个能力、范围、条件、时间和结果都能回溯到材料或用户确认。
- 未把预测、内部目标或个例写成确定收益。
- 冲突事实已解决或明确标为待确认。
- 旧方案、删除线内容和内部代号未进入正式稿。

## 商家表达

- 标题说明能力和价值，不使用空泛口号。
- 开头先讲商家场景，正文包含入口、操作、结果和限制。
- 专有名词首次出现时有解释，步骤可直接执行。
- 移动端段落短，列表层级清晰，没有大段堆砌。

## 图片

- 每个图位都有唯一目的和对应素材。
- 截图与文案中的页面、按钮和状态一致。
- 图片不暴露个人信息、测试账号、内部域名或敏感经营数据。
- 缺图不会用不相符截图顶替；无图版本已删除占位符。

## 发布

- 发布字段与正文一致，链接可访问，目标环境正确。
- 草稿已经读回核验，不以“写入命令成功”代替内容正确。
- 最终按钮保留给用户，交接时只剩一个明确动作。

## 自动校验

```bash
python3 scripts/validate_release_package.py --draft <draft.md> --type <single|standard|campaign|digest|announcement> [--image-plan <plan.json>]
```

返回码为 `0` 表示没有阻塞错误；警告仍需根据材料人工判断。
